# GameSeed Organization Profile

This repository maintains the public GitHub organization profile for **[GameSeed](https://github.com/gameseed-tw)**.

GameSeed is an emerging game-development education and talent-incubation initiative. Starting in Taiwan, we aim to build an open network of game creators, educators, and communities around the world.

## Read our introduction

- **[English — Organization Profile](profile/README.md)** (default language)
- **[繁體中文 — 組織介紹](profile/README.zh-TW.md)**

GitHub automatically displays `profile/README.md` on the [organization Overview page](https://github.com/gameseed-tw).

## Editorial principles

- Use **English as the primary public language**, with a separately maintained Traditional Chinese version.
- Keep the organization profile accurate, welcoming, and easy to navigate.
- Clearly distinguish plans and aspirations from confirmed activities, members, and partnerships.
- Share only approved public resources. Do not commit private proposals or personal information.
- Update both language versions when the mission, programs, or collaboration status changes.
