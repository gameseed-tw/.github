## 關於 GameSeed

**GameSeed 是一項從臺灣發起，以遊戲開發教育、人才培育與創作合作為核心的籌備中計畫。**

我們相信，每一位遊戲創作者都像一顆種子。透過學習、實作與交流的機會，種子能逐漸成長為團隊、作品、社群，甚至成為培育下一代創作者的導師。

GameSeed 以**嶺東科技大學數位媒體設計系**為最初發起基地，期望未來不受單一校園限制，逐步建立連結教師、學生、獨立遊戲開發者與產業社群的開放合作網絡，讓遊戲開發的知識與經驗能跨越校際及國界傳播。

## 🌿 SEED 四大核心理念

| 核心 | 內容 |
| --- | --- |
| **S — Skills｜技能培育** | 培養遊戲設計、程式開發與製作的實務能力。 |
| **E — Experimentation｜實作探索** | 透過可玩原型、創作實驗與實際專案累積經驗。 |
| **E — Exchange｜跨域交流** | 串聯教師、學生、創作者與遊戲產業社群。 |
| **D — Dissemination｜知識傳播** | 分享可重複使用的教材、技術與經驗，讓更多創作者成長。 |

## 🎮 我們希望培育的未來

GameSeed 預計逐步推動以下方向：

- **開放的遊戲開發教育：** 可共享的教材、工具與專案範本。
- **從實作中學習：** 遊戲原型、協作開發與 Game Jam 參與。
- **導師與團隊孵育：** 從基礎能力、遊戲作品到可持續發展的創作團隊。
- **教師與社群交流：** 促進校際、獨立開發者與產業社群的合作。
- **讓種子持續傳播：** 讓受培育的學生未來也能成為導師，協助更多校園與社群建立自己的創作環境。

## 🤝 從臺灣萌芽，向世界擴散

GameSeed 初期以**嶺東科技大學數位媒體設計系「遊戲製作培訓中心」**為實踐基地。

本計畫也延續過去與臺灣獨立遊戲開發社群的交流經驗，包括與 **TiGG** 的長期互動。我們希望未來能進一步邀請臺灣及海外的教師、學校、開發者與社群共同參與。

我們期待教材、知識與遊戲創作經驗，不只留在單一間教室，而是能成為其他學校與社群持續成長的養分。

## 🚀 計畫現況與參與方式

**GameSeed 目前處於規劃與初期籌備階段。** 課程、專案、參與機制及合作模式仍在規劃中；正式合作夥伴與活動資訊將於確認後陸續公布。

如果你關注遊戲教育、開源資源、人才指導或跨校合作，歡迎追蹤本 GitHub Organization，留意後續發展與參與機會。
